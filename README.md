\# Mis Ejercicios de Programación - Profe Paco



Este repositorio contiene las actividades organizadas por el orden en que las vimos en clase:



\## 📂 Primer Parcial: Fundamentos

\* \*\*Secuenciales:\*\* Ejercicios básicos de entrada y salida de datos.

\* \*\*Condicionales:\*\* Estructuras de control de decisión (if/else).



\## 📂 Segundo Parcial: Ciclos

\* \*\*Repetitivas:\*\* Estructuras de control de iteración (for/while).



\## 📂 Tercer Parcial: Estructuras Avanzadas

\* \*\*Arreglos:\*\* Manejo de vectores y listas de datos.

\* \*\*Cadenas (Strings):\*\* Manipulación de texto y funciones específicas.

\* \*\*Funciones:\*\* Modularización de código y retorno de valores.
